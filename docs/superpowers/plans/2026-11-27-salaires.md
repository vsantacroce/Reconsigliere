# Réconciliation des salaires : plan d'implémentation

> **Pour les agents :** sous-skill requis : superpowers:executing-plans (choisi : exécution dans la session). Étapes en cases à cocher.

**But :** générer, ouvrir et enregistrer depuis Reconsigliere l'Excel de réconciliation des salaires par exercice et par employé.

**Architecture :** classeur de paie (format 2025) → `lecture_paie` → fiche par exercice (`fiche`, corrections gardées) →
`reconciliation` (résumé en Python + classeur à formules) → onglet `onglet_salaires` et commande `salaires`.

**Technique :** Python 3.12, openpyxl, tkinter, unittest. LibreOffice (facultatif) pour recalculer les formules dans un test.

**Conception :** `docs/superpowers/specs/2026-11-27-salaires-design.md`

## Contraintes globales

- Tout texte visible en français, sans mot anglais.
- Aucune donnée réelle dans `tests/` ni `docs/` : employés fictifs (« Durand Alice », « Meier Bruno », « Rossi Carla »).
- Fichiers : `entrees/08_salaires/`, `entrees/08_salaires/fiches/fiche_salaires_AAAA.xlsx`,
  `sorties/salaires/Reconciliation_salaires_AAAA.xlsx`.
- Comparaisons de montants à 0.01 près ; montants arrondis à 2 décimales.
- Version 0.9.0 ; documentation vivante dans la même PR (`python outils/docs.py --verifier` et `--depuis origin/main` sans erreur).

## Points à surveiller

1. Fiche ou résultat ouvert dans Excel pendant l'écriture → `PermissionError` traduite en message « Ferme … dans Excel ».
   Test : écriture vers un chemin bloqué lève `FichierOuvert` (tâche 2).
2. Classeur de paie sans onglet attendu (ancien format) → erreur claire « onglet ANNEE introuvable », pas de trace Python (tâche 3).
3. Deux virements identiques (même jour, employé, montant) → identifiants distincts `-1`, `-2` et corrections gardées sur le bon (tâche 2).
4. Employé présent dans la fiche N−1 mais plus en N → il apparaît quand même dans le bloc « Restes N−1 » (tâche 4).
5. Aucun classeur ni fiche pour l'exercice choisi → l'onglet affiche « Dépose ton classeur de paie dans entrees/08_salaires »
   et les boutons Générer / Ouvrir ne plantent pas (tâche 5, vérifié à la main).

### Tâche 2 : la fiche

**Fichiers :** créer `src/reconsigliere/salaires/__init__.py`, `src/reconsigliere/salaires/fiche.py`.

**Produit :**
- `COLONNES_DU = ["employe", "net_du", "source", "remarque"]`
- `COLONNES_VIREMENTS = ["id", "employe", "date", "banque", "montant", "exercice", "part_salaire", "type", "libelle", "piece", "imputation", "controle", "preuve"]`
- `CORRIGEABLES = ["exercice", "part_salaire", "imputation"]`
- `class FichierOuvert(Exception)`
- `chemin_fiche(annee: int) -> Path`
- `identifiants(virements: list[dict]) -> None` (remplit `id` = `AAAAMMJJ-<employé sans espaces>-<montant à 2 décimales>-<n>`)
- `lire(annee: int) -> dict | None` → `{"du": [...], "virements": [...], "points": [...], "auto": {id: {...}}}`
- `fusionner(ancienne: dict | None, nouvelle: dict) -> tuple[dict, dict]` → (fiche, bilan `{"ajoutes", "retires", "gardees", "manuels"}`)
- `ecrire(annee: int, fiche: dict) -> Path` (onglets `du`, `virements`, `points`, `auto` masqué ; `PermissionError` → `FichierOuvert`)

Tests (`TestFiche`) :
- `test_aller_retour` : écrire puis lire rend les mêmes lignes (dates en `datetime`, montants en float).
- `test_ids_virements_identiques` : deux virements identiques → ids finissant par `-1` et `-2`.
- `test_relecture_sans_correction` : `fusionner(f, f2)` avec f2 = nouvelle lecture identique → bilan gardees = 0, fiche = f2.
- `test_correction_gardee` : `part_salaire` modifiée dans l'ancienne (différente de `auto`) → gardée ; `auto` mis à jour à la nouvelle valeur du lecteur.
- `test_preuve_gardee` et `test_net_du_corrige_garde`.
- `test_ligne_manuelle_gardee` (id vide) → présente, bilan manuels = 1 ; `test_virement_disparu_retire` → bilan retires = 1.
- `test_fichier_ouvert` : `ecrire` avec `openpyxl.Workbook.save` simulé levant `PermissionError` → `FichierOuvert`.

### Tâche 4 : réconciliation et classeur résultat

**Fichiers :** créer `src/reconsigliere/salaires/reconciliation.py` ; compléter `salaires/__init__.py`.

**Produit :**
- `resume(annee: int, fiche_n: dict, fiche_prec: dict | None, fiche_suiv: dict | None) -> dict`
  → `{"lignes": [{"employe","du","paye","reporte","paye_suivant","ecart"}], "total": {...}, "restes_prec": [{"employe","reporte","paye","ecart"}] | None, "points": [str]}`
- `ecrire(annee, fiche_n, fiche_prec, fiche_suiv) -> Path` : feuilles « Synthèse », « Dû N », « Reste N−1 » (si fiche N−1),

- `salaires.lire_classeur(annee: int) -> dict` (bilan de fusion), `salaires.generer(annee: int) -> tuple[Path, dict]`,
  `salaires.exercices_disponibles() -> list[int]`.

Tests (`TestReconciliation`, fiches construites en mémoire) :

- `test_synthese_formules` : cellules B5:F5 de « Synthèse » commencent par `=` (aucune valeur figée).
- `test_sans_precedent` : pas de feuille « Reste N−1 », pas de bloc du bas.
- `test_sans_suivant` : feuille « Payé en N+1 » présente et vide, point « Aucune fiche N+1 ».

- `test_recalcul_libreoffice` (ignoré si `soffice` absent) : après conversion, valeurs de la synthèse = `resume`.
- `test_generer_bout_en_bout` : classeur fictif → `lire_classeur(2025)` → `generer(2025)` → fichier existe.
