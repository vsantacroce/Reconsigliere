# 05_mes_corrections

Le fichier mes_corrections.xlsx est créé au premier lancement. Tu le modifies pour corriger l'outil :

- Feuille partenaires : un mot du libellé bancaire et le nom de partenaire à utiliser.
- Feuille transactions : pour un id de transaction, le partenaire, le PDF à lier, une explication ou un statut forcé.

Tes corrections passent toujours avant le rapprochement automatique.
